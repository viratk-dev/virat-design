# virat-design

A complete design methodology for premium minimal visuals — the way a world-class designer works, end to end. **Principles are fixed. Tokens are flexible.** Ships with a default aesthetic ("Virat defaults"); every color and font adapts to the user's brand without breaking the style's DNA.

## The Non-Negotiables

These never change, no matter whose brand it's for:

1. **Restraint is the luxury.** Default to 3 colors per piece (canvas + ink + one accent) — but the count follows the user's need, not a fixed ceiling. More colors only when the brief genuinely demands them; never decoration for its own sake. If in doubt, remove.
2. **Typography leads.** Max 2 font families. Headlines do the heavy lifting — no decorative clutter.
3. **One hero per page.** A single headline, number, or visual owns the composition.
4. **Whitespace is structure.** Minimum 8–10% safe margins; generous vertical rhythm.
5. **One accent, used sparingly.** A single accent color on 1–2 words or one element per page.
6. **Human-made, always.** No gradients, no glow, no glassmorphism, no neon, no generic AI-template look.
7. **Real assets only.** Official logos, never faked or recolored. No AI faces as heroes.
8. **Nothing ships without QA.** The checklist in [references/qa-checklist.md](references/qa-checklist.md) is mandatory.

## End-to-End Workflow

Follow all 8 stages. Detail for each in [references/process.md](references/process.md).

| Stage | What happens |
|---|---|
| **1. Brief** | Extract: the one message, audience, format/size, brand assets (logo, colors, fonts — if none, use defaults). Ask only what changes the design; assume the rest. |
| **2. Research** | Study the category's best work. Note what to borrow and what to deliberately avoid. |
| **3. Direction** | Define the art direction in one sentence (mood + hero + accent role). For big pieces, explore 2–3 directions and let the user pick. |
| **4. Tokens** | Build the project's token set: canvas, ink, accent, muted, line + display font, label font. Start from [Virat defaults](references/style-tokens.md#virat-defaults), then adapt per [adaptation rules](references/style-tokens.md#adapting-to-any-brand). |
| **5. Compose** | Pick a layout from [patterns](references/patterns.md). Write copy first — headline ≤ 6 words, subline ≤ 2 lines. |
| **6. Build** | Reference method: HTML/CSS rendered to PNG at exact pixels (crisp type, real logos). Type stays as type — never bake text into generated images. |
| **7. QA** | Run the full [checklist](references/qa-checklist.md). Fix everything. |
| **8. Deliver & iterate** | Deliver the file + a one-line design note. Iterate on feedback; never defend a failing design. |

## Virat Defaults (the starting aesthetic)

The signature look — used when the user has no brand assets. Fully specified in [references/style-tokens.md](references/style-tokens.md):

- **Canvas** `#F6F5F1` warm ivory · **Ink** `#151515` · **Accent** `#334EE8` royal blue
- **Display:** Plus Jakarta Sans 800, tight tracking · **Labels:** Space Mono, uppercase, wide tracking
- Pills, numbered sections, hairline dividers, soft white logo tiles

These are **defaults, not laws**. A fitness brand gets an energetic accent; a law firm gets a sober one. What stays constant is the *system*: color discipline, restraint, hierarchy — the exact palette follows the user's need. See [adapting to any brand](references/style-tokens.md#adapting-to-any-brand).

## What This Skill Is Not

- Not video editing — static images/graphics only.
- Not a logo generator — it art-directs layouts; brand marks come from official sources.
- Not a photo editor — it composes designed graphics.
- Not a fixed template — it is a methodology that adapts to any brand.
