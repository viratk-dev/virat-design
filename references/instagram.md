# Instagram & Social Specs

## Formats

| Format | Size (px) | Safe area | Use |
|---|---|---|---|
| Portrait post | 1080 × 1350 | 100px margins | Default feed post |
| Square post | 1080 × 1080 | 90px margins | Feed, grid |
| Story / Reel cover | 1080 × 1920 | 250px top/bottom (UI chrome) | Stories, reel covers |
| Carousel slide | 1080 × 1350 | 100px margins | Each slide identical frame |

## Carousel Rules

- All slides share: canvas color, footer style, kicker font, margin grid.
- Slide 1 = Cover pattern. Slides 2..N-1 = Feature pattern. Slide N = CTA/closer.
- Number every slide: `01 / 07` top-right in mono.
- Footer cue on slides 1..N-1: `SWIPE →`. Final slide: CTA instead.
- One idea per slide. If a slide needs two ideas, it's two slides.

## Type Scale (1080 wide)

| Element | Size | Notes |
|---|---|---|
| Hero headline | 120–200px | Jakarta 800 |
| Item name | 72–96px | Jakarta 800 |
| Subline / body | 36–44px | Regular, muted |
| Kicker | 28–34px | Space Mono, letterspaced |
| Pills / chips | 30–36px | Jakarta 600 |
| Footer | 24–28px | Space Mono, faint |

Minimum readable body: 32px at 1080 wide. Below that, cut words instead.

## Logo Tiles

- White rounded tile (28px radius), logo centered with 20% padding inside.
- Soft shadow `0 12px 32px rgba(0,0,0,.06)`.
- Official logos only. If no official logo exists, use a mono text tile — never a fake mark.

## Captions (separate from the image)

- Copy-paste ready, not hashtag-stuffed.
- Max 5–7 high-reach keywords, visibly separated from the caption body.
- Hook first line, value in the middle, CTA last.
