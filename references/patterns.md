# Layout Patterns

Six proven compositions. Pick one — don't invent a seventh unless none fits.

## 1. Cover

The opener. One message, maximum impact.

```
┌─────────────────────────┐
│ KICKER            2026  │  ← mono eyebrow + year/edition
│                         │
│   GIANT HEADLINE        │  ← 1–2 words in accent blue
│   subline, quiet        │
│                         │
│  ┌───┐ ┌───┐ ┌───┐     │  ← logo/feature tiles (optional)
│  └─01┘ └─02┘ └─03┘     │
│                         │
│              SWIPE →    │  ← footer cue
└─────────────────────────┘
```

## 2. Feature

One item, fully explained. The workhorse of carousels.

```
┌─────────────────────────┐
│ SERIES NAME     02 / 07 │
│                         │
│ ┌─────┐  KICKER         │
│ │LOGO │  Item Name      │  ← logo tile + mono kicker + Jakarta 800 name
│ └─────┘                 │
│ ─────────────────────── │
│ Description in two      │  ← ink, 2–3 lines max
│ lines, no more.         │
│                         │
│ ( FEATURE ) ( PILLS )   │  ← rounded chips
│                         │
│ BEST FOR · use case     │  ← mono line
│                         │
│ 02          tagline →   │  ← big number + footer
└─────────────────────────┘
```

## 3. Comparison

Two options, one winner. Tables, not paragraphs.

```
┌─────────────────────────┐
│        KICKER           │
│   Headline vs Headline  │
│ ┌─────────┬───────────┐ │
│ │  muted  │   blue    │ │  ← header row: loser muted, winner accent
│ ├─────────┼───────────┤ │
│ │  row    │   row     │ │  ← alternating ivory/white rows
│ └─────────┴───────────┘ │
└─────────────────────────┘
```

Rules: max 5 rows. Winner column always right, always accent header.

## 4. Stat / Number

One number, enormous. Nothing else competes.

```
┌─────────────────────────┐
│        KICKER           │
│                         │
│         100             │  ← number fills 40%+ of canvas
│      description        │
│                         │
└─────────────────────────┘
```

## 5. Quote / Statement

One strong line, centered, editorial.

```
┌─────────────────────────┐
│                         │
│   "The line itself      │
│    is the design."      │
│                         │
│   — attribution, mono   │
└─────────────────────────┘
```

Serif (Georgia) allowed here for editorial weight.

## 6. List

3–5 items, numbered, breathing room.

```
┌─────────────────────────┐
│ KICKER                  │
│ Headline                │
│                         │
│ 01  Item one            │
│ ───────────────────     │
│ 02  Item two            │
│ ───────────────────     │
│ 03  Item three          │
└─────────────────────────┘
```

Rules: hairline between items, generous padding, numbers in mono or Jakarta 800.

## Formal Variant (certificates, covers, invitations)

- Double frame border (outer 1.2pt, inner 0.6pt, 4mm inset)
- Centered serif or Jakarta headline
- Diamond/square motif divider
- Structured info boxes with hairline rules
- Signature lines at bottom with clear signing space
