# Presentations / Slide Decks

Slide design for keynotes, pitches, workshops, and class decks. Same DNA as everything else — restraint, hierarchy, one idea per slide.

## Sizes

| Format | Pixels | Use |
|---|---|---|
| Widescreen | 1920 × 1080 | Default — everything modern |
| Classic | 1024 × 768 | Only when the venue demands 4:3 |

## Deck Structure

```
01  Title       — the promise, maximum impact
02  Agenda      — 3–5 sections, numbered (optional for short decks)
03+ Sections    — divider slide + content slides per section
N   Closer      — the one takeaway + single CTA
```

## Slide Types

**Title.** Kicker → giant headline (1–2 accent words) → one subline. Generous whitespace. Nothing else.

**Section divider.** Big number + section name, centered. Gives the audience a breath.

**Statement.** One strong line, enormous, centered. For the lines that matter.

**Content (never raw bullets).** Transform bullets into:
- Numbered rows with hairline dividers (like the list pattern)
- Cards with a kicker + one line each (max 3 per slide)
- A simple diagram or flow (keep it geometric and minimal)

**Comparison.** Two columns, winner on the right with accent header. Max 5 rows.

**Stat.** One number filling 40%+ of the slide + one quiet line.

**Quote.** Centered, serif allowed, attribution in mono.

**Image.** One image, full-bleed or generously margined. Never more than one per slide. Caption in mono.

**Closer.** The takeaway as a statement + one CTA (contact, link, next step). No "Thank You" slides — end on value.

## Slide Rules

- **One idea per slide.** If a slide needs two ideas, it's two slides.
- **30-word ceiling.** No slide carries more than ~30 words. Speaker notes hold the rest.
- **Consistent chrome.** Same footer on every content slide: brand/series name left, slide number right, mono, faint.
- **Type scale (1920 wide):** headline 130–180px · body 44–56px · kicker 30–36px · footer 24px.
- **Build method:** HTML slides at 1920×1080, exported to PDF (print) or PNG per slide.

## What Kills Decks (never do)

- Walls of bullet text
- Clip-art, stock-photo collages, gradient backgrounds
- A different layout on every slide — consistency is the design
- Reading the slide aloud (design for the audience, not the speaker)
