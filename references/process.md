# End-to-End Process

How a world-class designer takes a vague request to a shipped graphic. Follow every stage.

## Stage 1 — Brief (5 minutes, not 50)

Extract only what changes the design:
- **The one message.** If the user can't say it in one sentence, help them find it. Everything serves this.
- **Audience.** Who sees it, where (feed, story, thumbnail), what action they should take.
- **Format.** Post / carousel / story / square — sizes in [instagram.md](instagram.md).
- **Brand assets.** Logo, colors, fonts? If none: "I'll use the default aesthetic — say the word to change it."

Ask max 2–3 questions. Assume the rest. Never stall the work waiting for answers you can decide.

## Stage 2 — Research (10–15 min for important pieces)

- Find 3–5 best-in-class references in the category. Note: what makes them premium, what clichés to avoid.
- Check facts, names, and official logos. **Research before design** — never guess a logo, stat, or spelling.
- Define what this piece will do *differently* from the references. If it looks like everything else, the direction is wrong.

## Stage 3 — Direction (one sentence)

Write the art direction before touching layout:

> *"[Mood] [format] where [the hero] carries the message, with [accent role]."*

Example: *"Confident carousel where giant numbers carry each slide, with blue reserved for the verdict line."*

For major pieces (brand launches, series openers): explore 2–3 directions, show them, let the user pick. For routine posts: pick the strongest direction and go.

## Stage 4 — Tokens

Build the project's token set per [style-tokens.md](style-tokens.md): canvas, ink, accent, muted, line + display font + label font. Write them down at the top of your working file — every decision references them.

## Stage 5 — Compose

1. **Copy first.** Headline ≤ 6 words. Subline ≤ 2 lines. Cut ruthlessly — every word earns its place.
2. **Pick a pattern** from [patterns.md](patterns.md). One idea per page; if a page needs two ideas, it's two pages.
3. **Place the hero.** The dominant element (headline/number/visual) gets 40%+ of the canvas and prime position.
4. **Support quietly.** Kickers, pills, footers, dividers — present but never competing.

## Stage 6 — Build

- Reference method: HTML/CSS at exact pixel dimensions, screenshotted to PNG. Crisp type, real logos, precise spacing.
- Type is always real type. Never bake text into AI-generated imagery.
- Official logos in white tiles with soft shadow; never stretched, recolored, or faked. No official logo → mono text tile.

## Stage 7 — QA (mandatory)

Run [qa-checklist.md](qa-checklist.md) in full. Read every word twice. Check alignment, margins, color count, accent discipline. Fix everything — "minor" issues don't ship.

## Stage 8 — Deliver & Iterate

- Deliver the file plus one line: what it is and the design decision behind it.
- Take feedback without ego. If the user says "kuchh alag" (something different), go genuinely different — never remix the rejected direction.
- Approved work is locked. New explorations become new files, never edits on top of approved work.
