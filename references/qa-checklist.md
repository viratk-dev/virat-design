# QA Checklist

Run every item before delivering. Fix all failures — nothing "minor" ships.

## Layout
- [ ] Safe margins respected on all edges (nothing touches the frame)
- [ ] One hero per page — a single dominant element
- [ ] Vertical rhythm consistent (no random gaps, no cramped clusters)
- [ ] Alignment is deliberate — every element aligns to something

## Color
- [ ] Color count is intentional — default 3 (canvas + ink + one accent); more only when the user's need genuinely justifies it, never as decoration
- [ ] Accent used on 1–2 words/elements only
- [ ] No gradients, no glow, no glassmorphism
- [ ] Grays are warm-toned, not cool

## Typography
- [ ] Max 2 font families
- [ ] Headline ≤ 6 words, no orphans, breaks chosen deliberately
- [ ] Kickers uppercase + letterspaced
- [ ] No typos — read every word twice
- [ ] Body text ≥ minimum readable size

## Content
- [ ] Real official logos only — none stretched, recolored, or faked
- [ ] Facts verified — no invented claims, stats, or names
- [ ] Copy is tight — every word earns its place
- [ ] CTA is singular and clear (one action per piece)

## Series consistency
- [ ] Same canvas, footer, kicker style across all slides
- [ ] Numbering correct and sequential
- [ ] `SWIPE →` on all but the last slide

## Export
- [ ] Exact pixel dimensions for the format
- [ ] Type is crisp (vector/text, not rasterized blurry)
- [ ] File size sane for the platform
